# CoreProject2

PROJECT SUMMARY

This project was based on analysing a case study to understand what the system needed to do. Using this information, we built a secure back-end system using Node.js and a SQL database to store and manage employee data.
The back-end handles user login, data validation, database queries, and error handling to ensure the system works correctly and securely. Security measures were added to protect data and keep the database accurate.
An existing front-end website was connected to the back-end so users can interact with the system. The project was managed and documented using GitHub, which allowed the team to work together and track changes.
Each team member contributed to different parts of the project. The final system is easy to use, secure, and clearly shows the value of the solution.
